## Documentation framework (light)

Every section and detail page uses the same specimen card:

1. **Preview** — component or token on a subtle surface  
2. **Meta** — variant title plus colored tags (`token`, component name, pattern, and so on)

Kit components live on `_Playground`:

- `Doc / Page title`
- `Doc / Specimen`
- `Doc / Tag` (Info / Success / Accent)

Pages bind the **Semantic** collection to **Light**. Canvas backgrounds are light solids (page backgrounds cannot bind to variables).
