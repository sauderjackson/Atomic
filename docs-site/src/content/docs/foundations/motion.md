The motion roles a screen may use. Write the "What to write" column in a component. The numbers are the values for the two test themes.

| Token | Job | What to write | Neutral light | Neutral dark | Okvy light | Okvy dark |
| --- | --- | --- | --- | --- | --- | --- |
| `motion.duration.control` | Duration of a control state change. | `var(--motion-duration-control)` | `120ms` | `120ms` | `120ms` | `120ms` |
| `motion.easing.standard` | Easing of a control state change. | `var(--motion-easing-standard)` | `cubic-bezier(0.2, 0, 0, 1)` | `cubic-bezier(0.2, 0, 0, 1)` | `cubic-bezier(0.2, 0, 0, 1)` | `cubic-bezier(0.2, 0, 0, 1)` |
