Names a status.

## When to use

Use it to mark a state the person needs to notice, next to the thing it describes.

## When not to use

Do not use it as a button. Do not invent a tone outside the four status roles.

## Props

| Prop | Values | Default | Required | Job |
| --- | --- | --- | --- | --- |
| `tone` | `success`, `warning`, `error`, `info` | none | no | Names the status. |
| `children` | none | none | no | The status label. |
