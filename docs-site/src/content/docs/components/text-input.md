Collects one short line of text.

## When to use

Use it for a single short answer, such as a name.

## When not to use

Do not use it for a long answer, a choice, or a search that needs its own molecule. Do not leave the field unlabeled.

## Props

| Prop | Values | Default | Required | Job |
| --- | --- | --- | --- | --- |
| `label` | none | none | yes | Visible name of the field. |
